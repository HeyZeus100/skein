# Interaction matrix: Chat, Models, Settings, Personas, Vault gate

Bead `skein-xtov.2`. Companion to `docs/ux/audit/AUDIT_CHAT_MODELS_SETTINGS.md`, which holds the evidence and finding IDs.

- **Base:** `main` at `009cbb6`.
- **What counts as a row:** one row per visible interactive element in the **running app**, meaning what `MainActivity` composes. Two kinds of non-interactive element also get rows, because users will expect them to be interactive: an inert settings row and a dead-end screen. Controls that exist only in `@Preview` or tests are left out; they are listed in audit §14.
- **Path shorthand** (`feature/…/kotlin/app/skein/feature/` is dropped):
  - `chat/` = `feature/chat`
  - `settings/` = `feature/settings`
  - `auth/` = `feature/shell/.../auth`
  - `nav/` = `feature/shell/.../nav`
- **Severity:** `—` means no defect was found.
