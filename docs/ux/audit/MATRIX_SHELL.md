# Shell interaction matrix (skein-xtov.1)

This matrix has one row per visible interactive element in the shell and navigation layer (brief §19), audited at `009cbb6`. The full narrative and evidence are in `docs/ux/audit/AUDIT_SHELL.md`.

**Reading the table**

- **Paths.** `shell/…` means `feature/shell/src/main/kotlin/app/skein/feature/shell/…`. `timeline/…` means `feature/timeline/src/main/kotlin/app/skein/feature/timeline/…`. `MainActivity.kt` means `app/src/main/kotlin/app/skein/MainActivity.kt`.
- **Where rows apply.** Every row is production code reachable from `MainActivity`, unless its State is FUTURE. FUTURE marks code that is compiled but not rendered in production; those rows are listed so the redesign knows the code exists.
- **Width abbreviations.** "C" = COMPACT (below 600 dp: Fold outer display, phones). "M" = MEDIUM (600–839 dp). "E" = EXPANDED (840 dp and up: Fold inner display at stock or owner density).
- **Severity** follows brief §47. "—" means no defect beyond polish.
