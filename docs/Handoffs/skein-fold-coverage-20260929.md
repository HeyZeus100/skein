## Foldable emulator lane

`.github/workflows/foldable.yml` is coordinator-dispatched, separate from the ordinary instrumentation suite. `-Pskein.foldableTests=true` adds test-only source and manifest; the default test APK and production APK gain no emulator networking permission. Posture requests now use the host's serial-targeted emulator console `fold`/`unfold`; `UiAutomation` retains absolute portrait/landscape rotation. The adapter still queries and preserves the actual API 35 state catalog, requires unique exact `CLOSED`/`OPENED` names, rejects malformed or ambiguous entries, and polls the committed state **and unchanged actual window geometry**. Its observation contract is pinned to [Android 15's device-state shell implementation](https://github.com/aosp-mirror/platform_frameworks_base/blob/cc8bb19595c661f5cf42f330457000e643c67d1b/services/core/java/com/android/server/devicestate/DeviceStateManagerShellCommand.java). No guest framework state override or synthetic display-size change drives this lane.

`foldable-console-bridge.py` uses only fixed private request/ack files through `run-as`, with a fresh 32-hex host run ID, strictly increasing sequence, per-request nonce, exact `fold`/`unfold` allowlist, bounded JSON and atomic writes. Every console mutation and acknowledgment write rechecks the disposable CI marker, strict `emulator-N` serial, `ro.kernel.qemu=1` and exact AVD name `skein_foldable_gate`. Commands have ten-second subprocess deadlines. Exact request replay can receive the cached acknowledgment but cannot repeat a mutation; timeouts poison the transport. The instrumentation waits for matching acknowledgments before checking committed posture and viewport geometry. No app socket or production permission change is required.

The adapter checks the exact AVD boot property before UiAutomation rotation, refuses a pre-existing state override, and retains both test identities and every geometry, Activity identity, gate and secure-window assertion. Its `@After` requests flat geometry and unfreezes rotation after its own changes. A failed transport cannot retry mutations; after any transport timeout the host withholds further posture changes and records the final posture as unverified. Guarded unfold cleanup is allowed only after its own positively acknowledged fold. The runner requests controller stop, bounds the join to 60 seconds, then escalates termination with a further two-second grace period and reaps its owned child, preserving failure status and logs. It preserves protocol events and failures on completion/interruption. The helper retains AGP's supported `android.injected.androidTest.leaveApksInstalledAfterRun=true` so private geometry, catalog and protocol files remain readable after the test task; the disposable emulator is then torn down.

[Official console documentation](https://developer.android.com/studio/run/emulator-console) defines absolute fold/unfold commands.
